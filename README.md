# Personal Webpage & Profile Card

A simple, responsive personal website built using fundamental HTML5 and CSS3 techniques.

## Features
- **Profile Card:** Displays photo, name, group info, and short biography.
- **Lists:** Structured custom ordered and unordered lists.
- **Custom Styling:** Modern typography, soft backgrounds, custom margins, paddings, and borders.
- **Interactivity:** Hover effects on navigation links.
- **Responsive Layout:** Adjusts dynamically to both desktop and mobile viewports.

## Technologies Used
- HTML5
- CSS3

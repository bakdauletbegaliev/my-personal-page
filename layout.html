Task 2 Overview: CSS Layouts & Positioning

This webpage demonstrates a classic structural layout built using only traditional HTML <div> elements and CSS positioning properties such as float and clear, without relying on modern layout systems like Flexbox or Grid.

The structure consists of a full-width header and navigation bar at the top, a two-column body split between a left sidebar menu and a right content area, and a grounded footer section at the bottom.
